ПОРЯДОК ВЫПУСКА

1. Распакуйте готовый ZIP в отдельную папку на прежнем Windows-компьютере.
   Запустите Prepare по README.ru.txt. Он проверит целевой сервер, создаст
   согласованную копию и повторит восстановление на его реальных данных
   в изоляции; затем подготовит API 0.9.0, включит блоги и соберёт APK14
   существующим ключом. Общедоступным обновлением пока остаётся APK13.
2. Выполните DEVICE_CHECKS.ru.txt на Android-устройствах. Сохраните
   конкретный APK, metadata и source receipt. Запустите Accept для записи
   фактически выполненной приёмки, привязанной к этим файлам.
3. Отдельный Publish опубликует ровно принятый APK без пересборки и проверит
   полный публичный файл по HTTPS: размер и SHA256 должны совпасть.
