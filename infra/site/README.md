# Файлы для сайта вечер.online (выкладываются на этапе сервера)

- `i/index.html` — страница ссылки-приглашения `https://вечер.online/i/КОД`: показывает код,
  кнопка «Открыть в приложении» (`vecher://open/i/КОД`) и «Скачать».
  На сервере нужно отдавать её для любых путей `/i/*` (в Caddy: `rewrite /i/* /i/index.html`
  в блоке сайта вечер.online — НЕ трогать /etc/caddy/krug.caddy).
- `.well-known/assetlinks.json` — чтобы Android открывал ссылку сразу в приложении (App Links).
  Вписать SHA-256 отпечаток ключа, которым подписан APK (для отладки — debug-ключ, для выпуска — свой).

Выкладка — через скрипты /root/site-kit (сначала test., потом основной домен), с бэкапом.
