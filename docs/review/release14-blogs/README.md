# Публичные блоги: проверка экранов кандидата 0.9.0 (14)

Изображения получены из настоящих Flutter-виджетов тестом
`app/test/blog_journey_test.dart`, а не генератором макетов. Данные вымышленные;
сервер и граница нативного плеера заменены тестовыми адаптерами.
Чёрная область с кнопкой — состояние до явного запуска видео. Эти изображения
не подтверждают декодирование видео на телефоне или выпуск APK.

Разрешения таблицы указаны в логических пикселях; экспорт сделан с плотностью
2×. Это верхняя часть прокручиваемых экранов. Тест проверяет отсутствие
переполнения, а функциональные сценарии отдельно прокручивают редактор и
проверяют сохранение и явное подтверждение публикации.

Повторить из `app/` с установленным Flutter 3.47.7:

```bash
VECHER_BLOGS_REVIEW_DIR=/tmp/vecher-blogs-review flutter test test/blog_journey_test.dart
```

Для повседневного прогона переменная экспорта не нужна: проверка размеров
остаётся активной, файлы не записываются.
