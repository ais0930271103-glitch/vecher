# Визуальная проверка «Интересного»

Кандидат 0.8.0 (13), 23 октября 2026 года.

Снимки получены из настоящих Flutter-виджетов после нажатия «Интересное»
во «Вместе», со стрелкой назад, темой приложения, Manrope и MaterialIcons.
Карточки используют фиксированные
тестовые данные; это проверка интерфейса, а не воспроизведения RUTUBE
на физическом устройстве.

| Снимок | Логический размер | Масштаб текста |
| --- | --- | --- |
| [Обычный телефон](phone-top.png) | 390 × 844 | 1.0 |
| [Узкий экран и крупный текст](small-large-text-top.png) | 320 × 844 | 1.3 |

PNG сохранены с коэффициентом пикселей 2. Проверены читаемость названия,
переносы режимов и форматов, подписи поиска, доступ к интересам и карточкам.
На обоих размерах нет переполнения или наложения элементов. Фильтры и
настройки прокручиваются вместе с лентой, оставляя доступ к материалам.

Воспроизведение из каталога `app/`:

```bash
VECHER_CONTENT_REVIEW_DIR=/tmp/vecher-interesting-review \
  flutter test test/content_journey_test.dart \
  --plain-name 'optional real-widget screenshots for content layout review'
```

Обычный полный `flutter test` пропускает только этот дополнительный
экспорт снимков, если переменная каталога не задана. Сценарии интерфейса
выполняются независимо от него.
